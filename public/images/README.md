# Images Folder

## Adding Lord Ganesha Image

To add the Lord Ganesha image to your wedding invitation:

1. Download a Lord Ganesha PNG image with transparent background from:
   - https://pngimg.com/image/64005
   - https://www.freeiconspng.com/img/46304
   - Or any other free PNG resource

2. Save the image as `ganesha.png` in this folder (`public/images/ganesha.png`)

3. Recommended image specifications:
   - Format: PNG with transparent background
   - Size: 500x500 pixels or larger
   - Colors: Golden/Orange tones work best with the website theme

The website will display a fallback Om symbol if the image is not found.

## Adding Krishna-Radha Background (Optional)

To add a background image:
1. Save your Krishna-Radha background image as `krishna-radha-background.jpg`
2. The CSS already references this image in the body background
3. Recommended size: 1920x1080 or larger for best quality

## Bride & Groom Corner Illustrations (Optional)

The site shows built-in chibi drawings of the bride and groom in the bottom
corners of the hero and RSVP sections. To replace them with your own pictures
(for example Ghibli-style portraits):

1. Save the groom as `groom.png` and the bride as `bride.png` in this folder.
2. Use PNGs with a transparent background, roughly portrait 200x260 proportions
   (any size works, 600x780 or larger looks sharpest).
3. The site swaps them in automatically; no code changes needed.
